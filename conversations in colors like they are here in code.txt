● I fixed it: the one failing test was Basic Authentication - Valid Credentials
  in tests/auth.spec.ts, and it now passes.

  Why it failed:

  page.goto: net::ERR_INVALID_AUTH_CREDENTIALS at 
  https://the-internet.herokuapp.com/basic_auth

  1. The test's first step opened /basic_auth without a username or password.
     That page requires HTTP Basic Auth, so the server returned 401 and Chromium
     aborted the navigation. The test failed right there.
  2. The next step, which put the credentials in the URL
     (https://admin:admin@...), never ran. That approach also doesn't work
     reliably in current browsers, so it wouldn't have fixed things anyway.

  The fix: the test now passes the credentials using Playwright's
  httpCredentials setting, so the browser answers the login challenge
  automatically:

  test('Basic Authentication - Valid Credentials', async ({ browser }) => {
    const context = await browser.newContext({
      httpCredentials: { username: 'admin', password: 'admin' }
    });
    const page = await context.newPage();

    await page.goto('/basic_auth');
    await expect(page.locator('.example p'))
      .toContainText('Congratulations! You must have the proper credentials.');

    await context.close();
  });

  All 12 tests in auth.spec.ts pass on Chromium, Firefox and WebKit. After that
  run I added a context.close() at the end of the test so the browser context
  gets cleaned up, and I didn't re-run after that change.
